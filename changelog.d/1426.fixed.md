QuantaStor disk details no longer show a negative block size, rotation rate, endurance, error count or byte total as a reading: such a value, and a power-on time between -1 and 0 that used to read as a zero-hour lifetime, is now shown as not read, while zeroes and negative Celsius temperatures stay valid. A peer node's device path admitted through a shared disk identity is no longer used as a SMART device on the selected node. Slot details saved by an earlier version no longer bring back a negative block size or rotation rate. QuantaStor SMART reads use only the device paths the current poll reports in rows owned by the disk's own node: a row that names another node in any of its owner fields, or whose owner fields disagree, supplies no path, and an I/O fence ID no longer stands in for the disk's owner; neither a saved device name or path list nor the device name of a saved manual bay assignment is used as a SMART device, and a saved device name is no longer restored. A bay whose current poll reports no device path of its own shows no device name, and the SMART details only a device read supplies show as unknown. Which node such a read is sent to is not changed here.
