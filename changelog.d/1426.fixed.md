QuantaStor disk details no longer show a negative block size, rotation rate, endurance, error count or byte total as a reading: such a value, and a power-on time between -1 and 0 that used to read as a zero-hour lifetime, is now shown as not read, while zeroes and negative Celsius temperatures stay valid. A peer node's device path admitted through a shared disk identity is no longer used as a SMART device on the selected node. Slot details saved by an earlier version no longer bring back a negative block size or rotation rate. QuantaStor SMART reads use only the device paths the current poll reports for that disk's own node; a saved path is never used, and a disk with none gets no SMART device read, so the details only that read supplies show as unknown.
