QuantaStor disk details no longer show a negative block size, rotation rate, endurance, error count or byte total as a reading: such a value, and a power-on time between -1 and 0 that used to read as a zero-hour lifetime, is now shown as not read, while zeroes and negative Celsius temperatures stay valid. A peer node's device path admitted through a shared disk identity is no longer used as a SMART device on the selected node.
