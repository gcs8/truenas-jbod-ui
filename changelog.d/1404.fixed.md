A BMC Redfish reply whose system or SimpleStorage resource has a wrong-typed member the reader uses (a list-valued Model, a numeric SerialNumber, a Devices value that is not an array) now ends as an unusable-response warning instead of an internal error, and a fallback storage resource with such a member adds none of its drives; a Redfish HTTP error reply whose error message is not a string now keeps the typed HTTP failure and the usual inventory warning, without that message, instead of an internal error; a TrueNAS websocket reply that answers a pending call with a non-object error member, or a DDP reply to a batched call with a message kind other than result, now fails that call at once as an unusable reply instead of a remote failure or a wait until the timeout.
