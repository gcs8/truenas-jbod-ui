SES status readers now publish a flag such as Predicted failure, Disabled, Swap, Hot spare, Do not remove, Fault sensed or Fault reqstd only when its whole value is 0 or 1; a malformed value like 10 or 1x reads as unknown instead of being shortened to its first digit. Merging two SES paths for the same bay now takes the enclosure path and element number from the same record, so a bay no longer carries a path and element pair that neither path reported, a later merge no longer folds it into a neighbouring bay, and its locate targets name only that bay.
