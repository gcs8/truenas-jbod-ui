Restore: an import now installs exactly the history database it validated, by content. Validation records the size and SHA-256 of the member it judged, read as a single file; activation copies the staged member through one opened file into a private copy, refuses the import unless that copy has the validated size and SHA-256, runs the integrity, required table and column, and timestamp checks on that copy and installs only it. A segmented import holds its staged hot database and segments to the validated digests the same way, and SQLite side files next to the staged member still refuse the import; a refused import leaves the current history unchanged.
