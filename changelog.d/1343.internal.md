The changelog gate now prints every file name, git argument and git error on one line, with control characters, line separators and undecodable bytes written as escapes, so a crafted fragment name can no longer start a log line of its own, and `changelog_fragments.py` escapes fragment names the same way. An explicit `--base` or `--head` is resolved to a commit id before any comparison, and a value that is empty, starts with `-` or names no commit is refused with exit 2, so git never reads it as an option.
