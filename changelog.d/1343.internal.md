Hardened the changelog tools: the gate and `changelog_fragments.py` print every file name, git argument, git error and argument error on one line, with control and formatting characters, line separators and undecodable bytes written as escapes, so crafted input cannot start a log line of its own, and a fragment whose text holds such a character other than its line breaks is refused. An explicit `--base` or `--head` is resolved to a commit id before any comparison, and a value that is empty, starts with `-` or names no commit is refused with exit 2, so git never reads it as an option. An event payload of the wrong shape, a missing git and a `CHANGELOG.md` that is not UTF-8 end with a fixed message instead of a traceback.
