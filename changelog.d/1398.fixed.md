Storage Fabric on CORE now reads every device type that mprutil prints, so an enclosure device count no longer leaves out STP, ATAPI or initiator rows. If a device row cannot be read, the device count shows as not read instead of a short total. A dedicated list or adapter reply that reports a utility error is now treated as not read, the same as its show all section. The adapter PHY counts are now kept only when each PHY row appears in its printed position.
