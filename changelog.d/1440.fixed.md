SES discovery no longer runs an elevated `sg_ses` page read on SCSI generic
devices that are known not to be enclosures. Before the read it checks each
device's peripheral type and INQUIRY data in sysfs, which needs no extra
privilege. It skips a device only when that identity was read in full and
shows a disk, tape or optical drive without enclosure services. A device with
a missing, unreadable or short identity is still read. The number of skipped
devices is logged, and the "found no usable sg_ses devices" message includes
it.
