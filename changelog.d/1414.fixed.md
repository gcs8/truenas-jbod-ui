Storage Fabric on CORE: an MPR target number is now 1 to 9 ASCII digits, so other scripts' digits are no longer targets and a superscript digit or an over-long digit run no longer stops the fabric build; an expander's enclosure handle, which mprutil prints in decimal while the device and enclosure lists print it in hexadecimal, is read as decimal, so from handle 10 up an expander keeps its enclosure link and selected-enclosure scope; and a failed controller read names its controller only for a unit of 1 to 4 ASCII digits, so any other unit token is recorded as a fixed rejected-unit reason and counted instead of being copied into the failure list and the snapshot export.
