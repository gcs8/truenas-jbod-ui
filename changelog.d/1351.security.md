The main UI, admin service and history service now share one browser write-origin decision: a state-changing browser request is accepted on the strength of its own Host header only after that header names exactly one valid host that passes the shared known-host check (an IP address, localhost, or for main and admin a name listed in `ADMIN_ALLOWED_HOSTS`), every Origin and Referer it carries must agree with the accepted origin, and a configured public origin stays authoritative.
