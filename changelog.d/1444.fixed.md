Backups: the slot detail cache, the SAS Fabric alias store and the mapping store no longer read a JSON state file of any size in one piece. Each read is limited to 64 MiB and 4,194,304 keys and values, checked before anything is parsed, which admits about 22,000 bays of the largest slot detail entry. A file over the limit is treated like an unreadable one, and a warning names the file; an alias change is refused with that reason. Backup import applies the same limit to those three members and refuses one over it, naming the member, so a backup the application would not load is refused before it is restored. A debug bundle that includes one of these files applies the same limit and refuses the export with that reason. A read of a file that is not a regular file, or that changes size while it is read, is not used, and a file nested more than 128 levels deep is refused before it is parsed, whatever the interpreter's own recursion limit; backup import refuses a member nested too deeply as invalid whether it was extracted to disk or kept in memory. Structural item and nesting counts now scan bytes once with bounded string and escape state, so long escaped strings do not build a per-escape scanning stack and punctuation inside strings does not consume the item budget.
