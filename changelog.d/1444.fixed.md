Backups: the slot detail cache, the SAS Fabric alias store and the mapping store no longer read a JSON state file of any size in one piece. Each read is limited to 64 MiB and 4,194,304 keys and values, checked before anything is parsed, which admits about 22,000 bays of the largest slot detail entry. A file over the limit is treated like an unreadable one, and a warning names the file; an alias change is refused with that reason. Backup import applies the same limit to those three members and refuses one over it, naming the member, so a backup the application would not load is refused before it is restored.
